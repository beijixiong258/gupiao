# A 股分析诊断与规则选股

个人使用的中国大陆沪深京 A 股研究程序，提供单股完整证据分析和范围选股两项功能。用户用自然语言提出股票、范围、条件或研究问题，程序取得并核验当次数据，再解释支持、反证、缺口与复评条件。

单股分析检验用户的猜想；没有明确猜想时，综合评价本股已有表现。范围选股在用户给定范围与条件内完成比较，默认用固定日终双榜和96种联合状态估计次日收盘涨幅。用户未提出风险要求时，不默认追求低风险或低波动，也不追加相应过滤。

本文件统一记录项目介绍、安装与使用、业务规则、指标口径、架构及维护说明；长期开发约定见 [AGENTS.md](./AGENTS.md)。个股与候选池只包含经真实目录核验的A股，指数仅作独立参照。程序不连接证券账户、不提交委托、不自动交易。

## 快速开始

运行环境：Windows、PowerShell 7（`pwsh`）、Python 3.11 或更高版本。

本项目在当前电脑直接使用，由智能体调用已有虚拟环境启动。现有 `.env` 保留真实配置并直接使用，无需重新填写或从示例文件生成。

```powershell
cd C:\Users\user\PycharmProjects\gupiaoyanjiu
& .\venv\Scripts\python.exe -B .\cli.py
```

运行时沿用已有模型Provider、Token和量化配置。环境文件按以下顺序首次加载，已有进程环境变量优先保留：

1. `%USERPROFILE%\.gupiaoyanjiu\.env`；
2. `.env`；
3. 当前工作目录的 `.env`。

填写凭据不等于数据权限已经开通；实际来源、失败及降级见报告。模型预检就绪也只说明当次请求成功，不保证后续网络或行情来源可用。

```powershell

```

单轮分析、限定范围或指定数量：

```powershell
& .\venv\Scripts\python.exe -B .\cli.py run -p "分析深科技"
```

## 单股完整证据报告

“分析深科技”进入独立的单股证据路径。程序先核验股票身份和可用日线，再尽量补充当前行情、财务、宽基指数和有界同行参照；不会把目标股票当成选股候选先筛掉，也不会改成全市场选股。

报告按内容组织，先给出可读摘要，再展示：

- 股票资料、实际日线截止日、历史覆盖范围、最新一根日线与当前行情；
- 趋势结构、动量与反转、K 线压力、价量确认、突破与回撤质量、相对强弱、风险与流动性、市场背景八组原始指标；每项保留当前数值、单位、中文含义和缺失情况；
- 完整技术摘要，包括均线、MACD、RSI、波动和回撤等已计算信息；
- 已取得的基本面与估值字段、比较样本中的估值分位、报告期、公告日和来源；
- 涨停回马枪状态、尾盘证据、七类补充诊断、可交易性限制；
- 支持证据、反证、风险、数据缺口、来源降级及重新评估条件。

八组原始指标不另行汇成技术总分，估值分位和RSI自身尺度也不是上涨概率。范围选股的预计次日涨幅综合分来自固定状态下成熟历史事件的收益统计，只换算为基点，不是给八组指标加权打分。报告不截断已取得财务或指标证据；遗漏内容由共享展示层按结构化事实补齐，不重算数字。

数据覆盖率与真实指标值分开呈现，覆盖率为零不表示指标为零。形态突破期限始终从基准涨停日计数，缩量不重置期限；缺少有效估值比较样本时只报告原始数值与限制，不断言估值高低。

指标注册表公开公式、窗口、最低样本数和缺失规则。缺失历史不填成中性值，缺失成交额不以价格乘成交量替代；单股与范围复用计算口径。范围深度复核核对身份、日期及未舍入指标，失效历史形态不进入当前风险摘要。

报告中的滚动统计注明实际有效样本数。相同指标定义只向模型传递一次，完整报告仍逐项展开；对话压缩保留本轮真实分析状态，避免完成后重复选范围。

自然语言解释逐项绑定注册表中的对象、名称、窗口和单位：市场参照子池均值不能改称沪深300收益，超额收益不能改称指数本身收益，14日ATR不能随相邻20日波动指标改写窗口。没有单独返回的指数收益只保留已给出的超额证据，不补猜数值。

“现有证据详解”按价格与趋势、价格位置与突破、动能、量价、相对表现、市场背景、下行风险、形态、财务和盘中状态展开本次已计算事实，并列明缺口、影响与补齐条件。20日收益与MA20只构成趋势判断的底稿；出现分歧时说明具体冲突，不以一句“证据有分歧”代替解释。模型正文不再固定压缩至300–600字，重要判断需说明数值、窗口、含义及反证；完整原始指标仍由共享展示层保留。均量比不能代替逐日放量核验，越过历史高点不能直接称为持续突破，过期信号仅作为历史观察。

同行、指数、财务、实时或分钟数据不可用时，保留其他可分析内容并标明“部分证据缺失”。某项窗口不足只让该指标不可用，不额外设置单股最低历史长度或最低同行数量的整体门槛。目标身份、交易日期或目标日线无法支持分析时，才返回相应不可用原因；程序错误单独报告。

| `supplemental_diagnostics` | 七个补充块的摘要、原始指标和缺失原因 |
| `ownership_analysis` | 通达信控盘来源观测、连续窗口变化、同日量价对照和解释限制 |

## 范围选股与用户条件

“小盘股”需要明确总市值或流通市值，以及具体上限；例如“推荐3只流通市值低于100亿元的股票”。例子中的100亿元不是默认阈值。口径或上限不明确时先澄清，本轮不取候选、不输出此前的全市场候选；当前不支持按市值百分位筛选。智能体必须显式传入市值条件，不能把“小盘股”当作无市值限制的全市场请求。

市值条件在基础价量检查之后、分批历史行情下载之前执行。“低于”不含上限，“不超过”包含上限。优先用本次请求取得的 `tushare_daily_basic` 日终市值，受限时采用 `eastmoney_daily_valuation` 明确逐日估值，逐股核验代码、分析日、有限正数和重复数据冲突；万元转换为元，分别保留总市值和流通市值口径。该接口在同次请求内复用，包括失败，不新增本地缓存。市值未核验者不进入候选，报告单列证据不足数量；接口限频或缺失不能解释为股票超过上限，也不使用盘中快照补猜。结果披露条件、通过数、未核验数，以及每只返回候选的原值、日期和来源取得时间。

范围默认核验股票身份、有效价量、完整分析日及固定状态需要的连续窗口；同状态历史结果支持估计后才参与综合排序。短历史或状态样本不足单列不可估计，不补值。用户明确的趋势、收益、波动、ST、上市时长或成交额限制经tiaojian核验；原5000万元观察基准不是默认门槛。

同状态样本、成熟事件、时间权重及缺失规则统一见[大盘与行业环境选股](#大盘与行业环境选股)。

`history_batch_size` 只限制每批取数规模，不截断范围。逐股先算完整时间窗口，再合并末日截面，避免构造全市场历史宽表。对潜在合格者完成本地技术核验、重新比较后，才为最终候选补财务、分钟及完整报告。`deep_analysis_limit` 和 `minute_candidate_limit` 仍限制昂贵补充请求，用户要求一只时只生成一份候选完整报告。展示数量不改写技术复核数和全部已确认合格数；程序错误停止并保留原因。

本次“最优”只表示在本次有效样本与固定状态统计中，预计次日涨幅估计最高；不表示已知未来收益或内在价值最高。估计均负仍可比较并明示负值。报告公开实际取数、技术复核、可估计、完整报告与展示覆盖。

用户有明确单股观点时，`yanjiu_wenti` 保存原始问题、可观测命题和不能核验的部分；`research_question` 给出逐项原值、支持/部分支持/直接反证/证据不足及复评条件。不能拿任意代理指标代替整个观点，更不能把指标核验转为未来概率；普通“分析某股”直接给综合分析。正ROE或正利润同比仅是财务背景，不机械加入看涨证据。同行优先真实行业一致且同日已核验总市值相近者，缺规模时披露补位与样本局限。正文先给结论，完整证据从共享结构一次展开。

支持次日涨幅及其历史条件统计估计。未来目标保留原文，保证盈利、已知未来最大收益及不支持期限等仍单列不可核验，不替换成过去ret_5。估计可用与已证明收益有效不同；不训练、不拟合、不自动调参。

已核验盘中快照单独解释今日变化及是否削弱原日线依据；实时与历史价格口径未对齐时不比较均线位置，盘中暂定变化不改写完整日线排序。

顶层 `status/outcome` 表示报告完成情况，`selection_outcome` 单独表示是否已有合格候选。必需比较指标、实时行情或基础价量证据不足时保留 `partial / information_partial`，说明尚无法完整确认是否合格；补充财务或分钟证据缺失时，已通过必需条件的候选仍可展示并披露缺口。明确未满足条件与来源不可用分别记录，工具和对话层继承部分完成状态。
范围结果同时披露两榜数量、重叠数、去重数、历史可用、统计覆盖、技术复核和完整报告数量；请求过不等于已经完成比较。来源不足不能当作明确不合格，技术程序错误终止本次结果。

`comparison_coverage` 记录实际比较覆盖；用户条件逐项返回 `met / unmet / unavailable`。市值汇总使用 `market_cap_filter`，返回股票保留 `market_cap_check`，列出条件、原值、单位、来源、日期和取得时间。`total_mv / circ_mv` 统一从万元转为元，上限亿元乘以100000000；“低于”为 `<`，“不超过”为 `<=`，缺失不能记成超标。

深度复核后没有合格候选时，可保留最多一个已复核的“观察对象（未通过选股条件）”，明确未满足项及缺失；它不是首选或备选。早期没有可分析数据或发生程序错误时不制造观察对象。

### 主板及命名范围核验

`fanwei_faxian.py` 按需读取当前行业与概念目录，再对真实候选做匹配和详情核验。命名范围策略接收核验结果，不接收大模型猜测的数据源分类。

整个沪深主板使用正式范围类型 `main_board`，不进入行业或概念发现链路。`xuangu_fanwei.py` 优先使用本次 `tushare_live` 股票目录且身份来源为 `tushare_stock_basic` 的 `market` 上市市场分类；分类缺失或质量不合格才降级，不因备用可用而重复强制请求。备用为已有东方财富 `clist` 接口的明确沪深主板类别 `fs=m:0 t:6,m:1 t:2` 完整分页成员，检查总数、重复身份、交易所标识，再与本次已核验A股横截面的代码、名称及适用日期交叉核验。现有东方财富日终估值表 `RPT_VALUEANALYSIS_DET` 的 `TRADE_MARKET` 原值可以保留为 `listing_market_code`，但该字段包含跨上市板的特殊类别，不能通过沪深A股集合减去科创板、创业板集合推断主板身份。未知或冲突分类保留为缺口，不能覆盖主源明确的非主板身份。仅分析已核验交集，保留取得时间、来源分类依据、失败与降级、未匹配及冲突记录、实际覆盖；恢复的证据不继续列为缺失，不能从代码前缀猜身份，不能将未匹配解释为非主板或已比较，也不能扩大到创业板、科创板或北交所。该范围复用现有公开数据接口，不新增积分权限要求。

唯一精确候选必须核对名称、代码和类别；多个真实候选由智能体结合上下文判断，仍含糊时才澄清一次。成功、冲突、失败和因请求限额尚未核验的候选都保留。核验失败不能作为排除另一个范围的事实，也不能把其余成功候选自动当作唯一答案。

## 大盘与行业环境选股

默认 `fenxi.selection_method=environment_96`。`legacy_24` 显式保留原固定五天观察的24状态对照；新模式环境缺失时不自动回退，也不混排两种估计。算法切换不改写既有研究记录。

### 固定日终双榜

取同一最近完整交易日的涨幅前100与成交额前100，合并去重后最多200只。两榜分别按来源未舍入原值降序，边界精确并列时按证券代码升序稳定截取；入榜顺序不代表最终预计涨幅优劣。

只对本次入榜候选请求历史和核验资格，失败或不合格后不从榜外补位。同状态历史统计只使用本次资格池中的有效股票，不加入榜外股票，也不重建历史每日榜单；保留当前存续池与事后入榜偏差。只有明确指定其他范围时才改变候选池。

### 24种价量状态与96种联合状态

24种个股状态由三个维度组成：

| 维度 | 固定划分 |
| --- | --- |
| 最近1日与5日收益方向 | 分别为正或非正，共4种组合 |
| 收盘价相对MA20的ATR14距离 | `(close-MA20)/ATR14` 为 `≤0`、`(0,2]`、`>2`，共3种 |
| 成交额变化 | 最近5日平均真实成交额／此前15日平均真实成交额为 `>1` 或 `≤1`，共2种 |

默认再结合沪深30020日收益的正／非正，以及申万2021二级行业20日收益相对沪深300的正／非正，形成最多 `24×2×2=96` 种联合状态。不预设任何状态更好，不训练、不拟合、不寻优。

当前状态需要20条连续有效OHLC及真实有限非负成交额，ATR14、前15日均额与后5日均额均须为正。均线、ATR、波动率等按各自窗口核验；可选MA60或MACD缺失不否决本已有效的状态，但依赖它的用户条件仍不能通过。

### 行业来源与历史归类

行业采用申万2021二级口径。当前账号实测无 `index_classify`、`index_member_all`、`sw_daily` 权限，默认访问申万官网分类历史与指数历史，核对公开分类表与官方资料，不通过代码前缀或Tushare当前行业文字猜测身份；不购买新权限。

有公开来源的股票当前行业参考可跨请求复用，保存于 `config.py` 定位的 `%USERPROFILE%\.gupiaoyanjiu\industry_references.json`，记录来源、查证日期、分类口径与近似标记。已有记录直接复用，新股票查公开资料，有新依据或人工纠正时更新。

历史统计允许把当前归类作为近似分组，披露事后归类与行业修订偏差，不冒充历史当时归属；`membership_usable` 与 `membership_verified` 分开，缺少精确历史归属不阻断有据的近似估计。行情、指数和计算结果仍每次重新取得，行业参考不构成行情缓存。

联合状态在原24价量状态之外加入两个条件：沪深30020日收益>0／≤0，以及申万2021二级行业20日收益减沪深300同期收益>0／≤0。共最多96种状态，保持120日窗口、20日半衰期和至少10个不同已知结果日期。原24统计作为独立对照，不与新估计混排。

| 指标 | 公式 | 展示单位 |
| --- | --- | --- |
| market_ret_5／20 | 沪深300收盘／对应5或20个交易日前收盘−1 | % |
| industry_ret_5／20 | 同一二级行业价格指数收盘／对应历史收盘−1 | % |
| stock_ret_5／20 | 本股同源前复权收盘／对应历史收盘−1 | % |
| industry_excess_ret_5／20 | 行业收益−沪深300收益 | 百分点 |
| stock_excess_ret_5／20 | 个股收益−所属行业收益 | 百分点 |

5／20个收益间隔分别需要权威日历覆盖6／21个交易日位置，仅要求相隔5／20个交易日的两端真实收盘价有效。按用户要求，行业允许沿用有公开来源的当前参考归类，保留查证日期，并将用于历史日期或后续复用的归类标记为近似；不冒充历史当时归属，不因缺少精确历史归属阻断统计。内部缺日保留原日期，不填价格、不压缩日历，也不阻断端点有效的区间收益。起止日缺失、重复、非法价格或完全没有有据的行业参考时仍留空。行业来源记录公开当前起止日期与价格。均线、ATR及波动率按各自窗口要求独立核验。两段超额存在代数关系，不能当独立确认。只有20日两项超额参与精确同预测的观察排序，不加入预计涨幅；5日值仅补充解释。字段原值均为小数，展示乘100。主基准固定沪深300，其覆盖不代表沪深京全市场。

### 成熟样本与次日期望分

默认按上述96种联合状态统计，24状态只作为独立旧规则对照。

评分只使用最近120个权威交易日内、截至分析日已到期的同状态参考事件。信号年龄a为分析日与信号日的交易间隔，分析日为0；0≤a<120，权重w=2^(-a/20)。20交易日半衰期和120交易日上限是用户确认的初始固定口径，未验证最优。较早行情仍可用于指标预热及逐期对照，不能混入当前主分。

估计事件为信号日收盘至下一权威交易日收盘，r=next_session_close/signal_session_close−1，沿用同源前复权口径，不扣交易费用。每日形成信号，仅当下一交易日已完成才参与统计；不使用未来行、未到期结果，未知不补零，不跨缺失日取下一条有效行情替代目标日。上涨指r>0，平盘进入非上涨组且跌幅为零；概率、条件均幅与总体均值使用相同的20交易日半衰期时间权重。最近120交易日内同状态至少10个不同已知结果信号日期才公开估计；该工程门槛不证明未来有效。当前状态需要20条连续有效OHLC及真实非负成交额，ATR14和前15／后5日均额须为正。事件数、不同信号日、有效事件量、按日期汇总权重的有效日期量、未知标签历史范围及相关性限制均保留。有效样本量不认证独立性，不额外限制候选；缺失不补50%或旧指数。

| 字段 | 定义 | 公开展示与缺失 |
|---|---|---|
| up_probability，P | Σw·I(r>0)/Σw，分母仅为结果已知事件权重 | 内部审计；不在选股报告列历史上涨概率。|
| conditional_upside_mean，G | 正涨幅事件的加权平均涨幅 | 内部审计；空条件组留空。|
| conditional_downside_mean，L | 非正涨幅事件的加权平均跌幅 | 内部审计；平盘损失0，空条件组留空。|
| expected_gross_return | Σw·r/Σw；两条件组可定义时等于P×G−(1−P)×L | 内部审计；单边样本仍直接计算总体均值。|
| expected_next_day_return | Σw·r/Σw，r=下一交易日收盘价/信号日收盘价−1 | 预计次日涨幅，展示为%，可正可负；不扣费用，不模拟成交。|
| composite_score_bps | 10000×expected_next_day_return | 次日期望分，单位基点；100分对应1%，不是0—100评分。|

收益名次只按未舍入expected_next_day_return降序，精确同值仍并列。同预测时，观察优先级依次比较industry_excess_ret_20、stock_excess_ret_20，不改写预计收益；全部相同则公开完整边界并列名单，代码只稳定展示。同状态共享估计。兼容recommendation_index等于composite_score_bps。当前状态raw_values包括ret_1、ret_5、ma20、atr14、atr_distance、amount_ratio_5_15。

当前状态要求20条连续有效OHLC与真实非负成交额，ATR14及前15／后5日均额为正。第20条有效连续日线起逐日形成信号，下一交易日收盘后成熟；同状态至少10个不同已知结果日期才公开估计。有效样本量只披露集中程度，不作门槛；不用核相似度或删日稳定性过滤，不支持时不补中性分或旧指数。

同时报告已知与未知事件、不同信号日期、有效事件量及有效日期量。有效量=(Σw)^2/Σ(w²)；有效日期量先将同日事件权重相加再计算，反映日期权重集中程度，不证明日期独立。按日期块进行探索性重抽样时保留原样本时间权重，区间只反映当前样本不确定性，不是未来收益范围。未知标签上下界采用同一权重，仅留内部审计。

最近60个交易日内已到期的信号逐期检查：每期以当时为截止日，重新应用120日上限、20日半衰期与10个已知日期门槛，只纳入到期日不晚于当时的样本。逐股将当时同状态预计次日涨幅与该股随后实际次日涨幅成对比较，按日期等权汇总预计均值、实际均值、偏差及绝对误差；保留逐期原值和无法比较原因。禁止用这些结果调参。历史证券池仍是本次存续资格池，未重建历史成分，因此检查只是存在选择偏差的参考检验，不是无偏的组合回测或已验证的未来预测。

每只候选保留当前环境、旧24估计对照、样本覆盖、相邻比较，以及首个未展示候选比较中的首个决定字段和双方原值。并列跨越报告数量上限且无法唯一选择时，公开全部边界名单；有限完整报告只作为边界示例。五日相对表现仅补充解释，不设行业名额或新的风险过滤。

预测目标始终为信号日收盘到下一权威交易日收盘的同源前复权收益，不扣费用。盘后决定无法按已过去的收盘价成交；没有买卖时点、真实成交及费用证据时，不输出可实现交易利润。

## 指标口径

本节集中记录指标定义、公式、单位、窗口与缺失规则。统一注册表是数值和中文释义的来源；指标、排名和同义变换不按数量投票，也不重复加入预计收益。

### 八组原始指标

| 组别 | 主要内容 |
|---|---|
| 趋势结构 | 均线间距、20 日对数价格日均变化、趋势变化与波动比、短中期均线关系 |
| 动量与反转 | 多周期收益、RSI、MACD DIF 与柱体 |
| K 线压力 | 跳空、日内收益、收盘位置、实体与上下影线 |
| 价量确认 | 量比、成交额异常、价量相关与量价残差 |
| 突破与回撤质量 | 突破距离、放量、回撤与停滞 |
| 相对强弱 | 本次样本、真实同行和宽基指数的相对表现 |
| 风险与流动性 | ATR、波动、振幅、回撤、真实成交额与换手率 |
| 市场背景 | 比较样本和行业收益、广度、离散度与宽基背景 |

`yinzi_gongcheng.py` 的 `FACTOR_REGISTRY` 与 `factor_definition` 统一提供中文名称、单位、含义、显示倍数、公式、窗口、最低有效样本要求、缺失规则和来源口径。输出 `daily_factor_analysis.groups` 中每组含 `values`、`metric_definitions`、`missing_fields`、`available_factor_count` 和 `factor_count`。因子汇总保留股票代码和实际交易日期。

定义中的 `label`、`unit`、`meaning`、`display_scale` 分别说明中文名称、单位、含义与显示换算。区间收益共用 `yinzi_gongcheng.interval_return`，先按权威日历保留日期位置，再核验两端价格；展示层不另维护一套定义。

指标定义同时传递同源标识、输入要求、日线频率和可用时点，供 AI 识别同义字段及适用边界。收益与收益排名、同一个超额的兼容别名不能当作独立上涨确认。市场方向分歧只表示指数与本次比较池未形成同向强弱，不等于本股横盘。

允许不足20条的滚动统计额外保留各股本次实际有效样本数 `valid_observations`，包括零样本。工具消息将重复定义提取到顶层 `indicator_definitions`，逐股用 `definition_ref` 引用并保留各自样本数；展示层从同一注册表展开，完整数值、定义和缺失项不减少。

展示层消费这份定义。例如原始收益 `0.05` 按定义显示为 `5%`；量比显示倍数，金额显示元；RSI 仍保留其自身的 0–100 指标尺度。上述都是指标的数学单位，不能被改称为综合分或上涨概率。可用字段数只是报告覆盖情况，不会换算成置信度分。

来源记录中的 `feature_coverage` 表示该字段有效观测占比，独立展示为覆盖率。例如 `0.9687` 只能表示覆盖率 `96.87%`，不能套用同名指标解释成收益或波动率；覆盖率为零不表示换手率、收益等原始指标为零。MACD 的陈旧信号与行情报价过期也分别解释。

八组原始指标不各自产生复合分或市场状态总分。新综合排序只消费下文固定状态的历史参考事件；旧R/E/U及其分位保留诊断和研究，其他原值、排名、同义字段和相关变换不能重复加分。数学定义中的指数平滑、成交量或成交额加权仍按公式保留。

### 原始数据与比较口径

- N日区间收益按权威日历定位相隔N个交易日的两端有效收盘价，内部缺口保留而不阻断该项收益；N日均线仍需要N条连续有效收盘价。坏行不删除后拼接，重复或无效日期不作为有效观测。申万主、备用源的时间统一转换为北京时间交易日，再与无时区的权威日历对齐，避免时区差异导致有效行情丢失。
- 个股整段历史覆盖率只披露，不设默认90%通过门槛；来源层将历史缺口保留为空行，由上述窗口规则决定哪些指标可算。较早缺口不能排除最近21条价格已完整的范围候选，也不能阻断单股已有证据。
- 日线按本次请求逐源核验有效且唯一的日期、最新完整交易日和必要价量窗口。范围要求最近20个权威交易日的开高低收有效且高低关系一致、真实成交额有限非负，前15／后5日均额与ATR14为正；采用与状态计算相同的公式核验，必要条件不足时在既有限额内尝试备用源。单股仍只要求目标日有效价格，不增加历史长度或成交额门槛。整段采用一个合格来源，不拼接复权价格；复权因子须按日期一对一对应且有限为正，缺失或重复不能前后填充。历史缺失行保留原交易日；形态D7/D14同样不能删除缺失日后重新计数，缺口无法确认的条件保留未知。分钟成交量由来源的手统一换算为股，成交均价=成交额（元）/成交量（股），不按价格大小猜单位。
- EMA、RSI、ATR 沿用首个有效值作种子的 `adjust=False` 递推口径，遇缺失后重新预热。RSI 的涨跌幅以首个有效差分作种子；本程序没有改为“首14期简单均值作种子”，短历史时与采用该口径的软件可能有差异。MACD 使用 EMA12、EMA26、DIF的EMA9，柱值为 `2*(DIF-DEA)`；完整柱值至少需34条连续收盘价。递推定义见 [pandas 官方文档](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.ewm.html)，常用参数与TR定义参考 [MACD](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/macd) 和 [ATR](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)。实际结果以本程序公开的初始化、倍数和缺失规则为准。
- `position_20` 历史不足或价格范围有缺失时留空，只有完整20日全平区间约定为50%。日内高低价相等时收盘位置留空；缺失开盘价不能用收盘价替代计算影线。横截面与单股复用这些口径。
- 成交额相关指标仅消费真实非负 `amount_yuan`；禁止用收盘价乘成交量补值，负额不能截成零。20日均额需20条有效值；成交额异常与相关系数使用最近20条中的至少10条/对有效观测，窗口与最低样本不是同一概念。
- `wvma_20` 的每日报酬权重为真实成交额相对20条窗口中位数之比，并截在0.25至4；基准至少10条金额，最终波幅至少10对有效收益和权重。分子、分母使用完全相同的配对。此数学权重不参与选股综合打分。
- `volume_price_residual_20` 使用带截距的一元线性拟合，收益与成交额对数变化至少10对有效观测；均值、协方差、方差使用同一配对，输出当前残差，不作未来预测。
- 前20日高点距离严格使用当日前20条完整有效高低收盘，不以10条替代20条。突破与均额比的乘积不能当作独立确认。旧字段 `low_volume_long_lower_shadow` 实际使用均额比，公开名称及说明已明确这一点。

- `price_turnover_corr_20` 使用真实逐日换手率，计算日收益与换手率日变化的 20 日相关，至少需要 10 对有效观测。输入 `turnover_rate=5` 表示 5%；缺失或常量时不可用，不能复制成交额相关系数。单日快照不能冒充历史换手序列。
- `wvma_20` 是成交额加权日收益均方根，描述无方向波动；数值高不能直接解释成更有利的股票状态。
- 行业统计按真实标签和交易日分组，每项至少五个有效观测。单股真实同行不足时记录缺失，不把整个比较池称为行业。
- 概念范围成员的行业缺失时保持缺失；只有已核验的行业目录范围可补充对应行业名称，已有成员行业不被覆盖。
- 比较池广度只代表本次取得的样本。当前行业标签回看历史不等于历史成员重建；沪深 300 等宽基指数单独作为市场参照。

### 缺失与窗口要求

- 区间涨幅使用按权威日历定位的两端价格，内部缺日不影响该区间涨幅。波动率等使用的20个逐日收益仍需要连续21条有效收盘价，60日回撤需要60条有效收盘价；不删除缺失日、不缩短指标窗口。

## 结构与行情时点

### MACD结构与独立回放

MACD 结构识别零轴背景、真实交叉、柱体动能以及快线和柱体的顶底背离。交叉记录发生日、新鲜度和失效状态；背离拐点默认左二、右二交易日确认，信号日期取右侧确认完成日，不回填到拐点日。距离按价格尺度标准化，参数集中在 `fenxi.macd_structure`。这些结构与市场、相对强弱、价量和风险一起解释，不单独产生买卖结论。

七类补充诊断是下行风险、均线偏离 ATR 倍数、20 日价量压力、流动性稳定性、营收与利润增长、盈利与现金流核对、财报时点与来源。单股和范围深度复核共用已有数据计算，缺失与零值分开显示。CMF 只描述收盘位置和成交量的压力，不是实际主力资金净流入。

研究侧保留独立的 `macd_huifang.py`，只接收调用方提供的内存历史面板。它按实际确认日回放，处理次一交易日执行、停牌、封板、整手、成交参与率、滑点和成本，并披露基线与历史时点覆盖限制。它不训练或发布预测，也不自动修改生产筛选规则；具备回放能力不等于已经取得可靠的真实历史增益结论。

### 形态期限与解释

东方财富快照和成分接口读取逐股 `f124` 更新时间（Unix 秒），转换为北京时间，同时保留来源日期；一次小样本直连核验确认了该字段的响应，正式调用仍检查缺失和无效值。取得时间不能代替来源时间。来源日期与待核验交易日不一致、来源时间在未来，或盘中缺少来源时间时，当前成交核验不通过，已有完整日线仍可用于诊断。报价更新到核验时点的秒数单独显示，120秒有效交易时段延迟是工程核验口径，不是成交保证。收盘前报价不能用作收盘确认。

单股和范围候选复用证据概览，明确价格与短中期均线、量能、相对表现、市场背景、下行风险、形态适用状态及真实分歧。复评条件来自当前有效 MACD 信号和适用形态的已计算条件；失效或未形成信号的原始状态仍可查阅，不继续支撑当前判断。不适用形态不等于利空，完整历史不等于已经验证的上涨胜率。

涨停回马枪的 `rule_semantics` 明确交易日计数起点与配置期限：基准涨停日为 D0，之后第一个交易日为 D1；默认缩量窗口为 D1～D7，突破必须晚于缩量且不晚于同一基准的 D14（含 D14）。缩量不重新起算14日。实际配置、缩量及突破距基准的交易日序号一并返回，不推断未来日历日期。

内部设问和推演不作为报告内容。公开提供关键证据、反证与限制，完整指标继续保留；不把每个价格衍生指标机械解释成一个独立买卖信号。

- 单股使用有界比较池，范围分批全量请求并只合并最新因子截面；潜在合格者完成技术复核后，分钟和深度财务请求限于最终展示候选；
- 范围技术摘要就地复用同次因子构造的完整特征，复核继续检查身份、日期和未舍入原值；只保留摘要，不另存全市场历史特征宽表。MACD 拐点批量计算保持相同窗口、容差、确认日和缺失规则；
- 数据源失败、时点不一致和字段缺失进入结构化结果，外层不会把不可用或程序错误包装成完整分析。

特征、技术摘要及因子增强的意外计算异常立即终止本轮，统一返回 `error / program_error`，不跳过出错股票后继续发布候选；来源层已明确返回的缺失、不可用及短历史仍按原有证据状态处理。

单股与范围共用行情质量和可交易性计算。范围将当前硬性限制用于过滤，单股将这些限制作为报告中的证据保留。范围详情核验部分失败时，保留尚未确认的候选，不把失败当作排除证据；日线主源非空但不合格时，在既有限额内尝试备用源，各源遵循相同的对应请求质量要求。

日线按本次请求逐源核验有效且唯一的日期、最新完整交易日和必要价量窗口。范围要求最近20个权威交易日的开高低收有效且高低关系一致、真实成交额有限非负，前15／后5日均额与ATR14为正；采用与状态计算相同的公式核验，必要条件不足时在既有限额内尝试备用源。单股仍只要求目标日有效价格，不增加历史长度或成交额门槛。整段采用一个合格来源，不拼接复权价格；复权因子须按日期一对一对应且有限为正，缺失或重复不能前后填充。历史缺失行保留原交易日；形态D7/D14同样不能删除缺失日后重新计数，缺口无法确认的条件保留未知。分钟成交量由来源的手统一换算为股，成交均价=成交额（元）/成交量（股），不按价格大小猜单位。

宽基指数复用本次权威交易日历：当前20日收益核验当日与20个交易日前的两端收盘价；必需端点缺失、重复或无效时尝试已有备用源，整段采用合格来源，不拼接价格。内部缺日保留原交易日，不阻断端点有效的区间收益；波动率仍要求连续21条有效收盘价。短个股历史可以独立取得足够的指数日历范围，不增加单股历史门槛。逐源质量、缺失日期、必需端点及降级原因保留在结果中。

横截面的换手率和流通市值只有在逐行确认日终来源、行情日、估值日与目标日线日一致后才能填补日线指标；当前明确支持的日终补充来源是 `tushare_daily_basic` 和 `eastmoney_daily_valuation`；公开备用的日终收盘价还需与同日原始日线交叉核验。已有有效历史值保留，缺失补充值不覆盖。实时或时点未核验字段保留在独立原始资料中，不注入上一完整交易日。

本地保留程序配置、用户配置的凭据、可选对话文本与“需要重新分析”标记，以及默认仅含状态和耗时等元数据的运行记录。按用户要求，另保存有公开来源的逐股行业参考笔记，记录来源、查证日期、分类口径和近似标记。运行记录默认不超过 14 天、100 次和 100 MB，可在连续对话中用 `/clear-runs` 清除。行情、范围目录、因子和计算结果不作为本地缓存；进程重启后重新取得行情并分析。

运行记录裁剪、`/clear-runs` 和临时运行目录回收统一移动到当前用户的 `Desktop/智能体回收站/垃圾桶`，不永久删除，不覆盖同名记录。目标必须位于指定工作目录内，目录链接和垃圾桶本身不可作为清理目标；自动裁剪或临时目录移动失败时保留原目录并记录警告，继续交付分析结果；显式清理失败仍报告错误。

ChatGPT OAuth 适配器将应用系统提示映射到 Responses 的 `instructions`，保留用户消息和工具调用往返内容，避免把后端不接受的 `system` 消息放入 `input`。模型预检使用该正式适配器发起最小文本请求，单次超时15秒且不重试；收到有效文本才返回就绪。凭据存在不代表网络、模型权限或推理可用，超时和认证失败均报告为关键失败。其他提供方保留既有检查方式。

腾讯前复权日线接口的结束日为排他上界：适配器请求上界加1个自然日，返回仍严格裁剪到原始起止日，不改变分析截止日，不拼接快照。目录与日线保留并集，缺失身份、日线及衍生目录覆盖限制进入结构化结果，不能通过inner join静默遗漏股票。

来源请求保留证书校验、超时、有界重试、取得时间、失败与降级记录。已恢复且通过同等质量检查的证据正常参加分析，主源失败保留为来源历史，不继续冒充当前缺失。

`rizhong_guzhi` 按同一请求与交易日复用日终估值，包括失败结果；代码、日期、原始收盘价、单位及完整日终标记逐行核验，实时快照不能升级为历史日终估值。

### 意图识别与报告状态

MCP 是同一分析工具的薄包装，股票名称/代码、范围与数量直接交给业务入口，不经过自然语言对话的意图识别节点；业务入口继续核验身份、范围、条件和数据。`ClarificationRequest` 等小型值对象负责一个问题、选项与回答，Windows Rich 适配器负责界面。没有交互回调的单轮命令和 MCP 使用普通文字澄清。

自然语言编排明确分为意图识别、工具执行和结果解释。`duihua/intent.py` 每轮独立调用一次模型，识别阶段只开放内部 `record_intent`，不开放业务工具或取得市场数据。结构化意图分为 `single_stock / selection / explanation / usage / clarification / unsupported` 六类，并记录 `requires_market_data`、股票与范围原话、`requested_count`、显式条件、研究问题、`unverifiable_requirements` 及缺失信息。选股的 `scope_kind` 明确为 `daily_leaderboards / all_market / main_board / named_scope`：未限定范围时使用固定日终双榜，明确要求完整全市场比较才使用全市场；整个沪深主板走正式市场范围；普通命名范围走动态发现。仅真实含糊的对象或范围指代进入澄清，唯一指代从完整对话解析到已经出现的名称或代码，身份仍由业务工具重新核验。识别失败仍须停止，不能借默认范围继续执行。识别依据完整对话，不能用静态行业枚举代替动态范围核验；需要新市场判断的追问应归入相应分析路径。

`requested_count`只记录明确1至10数量，其余null；工具shuliang保持一致。次日涨幅及其历史条件统计估计是selection现有能力，其他期限、保证盈利、已知未来最大收益等保留原研究问题及unverifiable_requirements；不能改成ret_5过滤或静默改期限。MCP直接业务调用独立于自然语言意图节点。

`duihua/loop.py` 根据意图筛选可用工具，执行前再校验单股对象、命名范围和研究问题原文，防止模型越过用户对象或范围、静默丢弃观点。识别失败终止本轮，不默认全市场；分析与必要澄清路径缺少对应工具执行时，不把模型正文包装为完成。解释、咨询和不支持路径不开放业务工具，必要澄清继续使用现有澄清契约。模型调用返回后再次核对取消状态，避免取消后继续分派行情工具。该节点不增加数据源、权限或编排框架，不改写量化排序、条件及业务状态继承。

本轮意图与显式条件放入系统上下文，并在对话压缩后保留；完整意图只随内存结果返回，运行记录仅记录该阶段的状态、耗时等元数据，不保存完整识别载荷。保留有效当前结果用于本轮解释，已持久化会话只保留文字和需要重新分析标记；旧预测阶段、旧评分结果和不可恢复分析标记不能当成当前证据。

`fenxi_zhanshi.py` 构造共享确定性证据报告。单股、返回候选和观察对象共用组件展示，八组每项数值、单位、中文含义与缺失均可见；技术、财务、形态、尾盘、补充指标和来源不按固定条数截断。未知字段保持可见原名，不编造定义。模型省略某块时补齐规范内容，避免追加重复报告；不靠强制买卖标签、分数或全篇数字关键词检查来决定成功。

`dangu_zhaiyao.py` 同时供单股与范围候选使用，消费既有技术、因子、形态、尾盘和补充诊断，整理证据背景与分歧，不重算指标或改变候选次序。`evidence_context` 和 `evidence_conflicts` 是公开观测关系，不是内部思维链。当前有效信号的失效条件进入复评条件；不适用形态和历史过期状态保留查阅，不混入当前支持或风险。

`shuju_yuan.py` 的行情时点核验统一约束可交易性和尾盘，编排层也据此决定是否允许快照参与盘中形态。原始快照保留用于说明来源；未核验价格不代替完整日线诊断参考价。行情适配读取逐股来源时间，元数据中的空日期不再覆盖行级有效日期。详见本文件的[指标口径](#指标口径)和[结构与行情时点](#结构与行情时点)。

状态语义如下：

| `status / outcome` | 含义 |
|---|---|
| `ok / analysis_success` | 单股完成当前证据分析 |
| `partial / information_partial` | 单股保留可分析证据，部分来源或指标缺失 |
| `ok / recommendation` | 范围取得通过条件的研究候选，内部名称不代表买入指令 |
| `ok / no_recommendation` | 范围没有股票通过本次条件 |
| `clarification_required` | 身份或范围需要澄清 |
| `unavailable / data_unavailable` | 必要数据不能支持当前业务 |
| `error / program_error` 或其他错误结果 | 计算或执行失败，保留原因 |

外层运行状态必须继承业务结果。`partial` 不能改称完整成功，`unavailable` 和 `error` 也不能因为模型产生一段文字就显示为成功。

### 旧R E U指数公式与研究

以下原始量与旧指数继续保留诊断和独立研究计算，不参与新的生产排序或作为不可估计状态的回退。

旧指数曾作为自定义排序规则，描述同日同范围内的相对量价状态，不是收益率、上涨概率、置信度或未来一周收益承诺。固定权重是产品取舍，不是训练所得参数，也没有被预设为最优。

以分析日为t，C为同源同复权口径的有效收盘价，A为真实日成交额（元），定义：

| 原始量 | 公式 | 单位、窗口与缺失规则 |
|---|---|---|
| 20日收益R | `C[t]/C[t-20]-1` | 小数比例，显示乘100为百分数；需要连续21条有限正收盘价。|
| 带方向路径效率E | `(C[t]-C[t-20])/sum(abs(C[k]-C[k-1]))`，k=t-19…t | 比例，范围[-1,1]；同样需要21条连续有效收盘价，路径变化总和为零时缺失，不补零。负值表示净向下。|
| 上涨成交额占优度U | `sum(sign(C[k]-C[k-1])*A[k])/sum(A[k])`，k=t-19…t | 比例，范围[-1,1]；需要21条连续有效收盘价及对应后20日真实有限非负成交额，总额须大于零。平盘日成交额进分母，分子贡献零；缺失或负额不补值。不是主动买入额、主力净流入或账户持仓。|

只有分析日、窗口与范围一致，且R、E、U全部有效的股票进入共同比较池；不能让三项各用不同有效样本。N为共同有效股票数，N<2时不发布指数。每项使用平均升序名次处理原值并列：

`p(x_i)=(average_rank_ascending(x_i)-0.5)/N`

价格组 `P=(p(R)+p(E))/2`，量价组 `V=p(U)`，推荐指数：

`I=100*sqrt(P*V)`

价格组与量价组几何等权，价格组内部两项等权。分位和组分按0–1保存，指数按0–100尺度保存，不附百分号；实际有限样本分数通常不取到0或100。禁止将缺项补50、临时重配权重或按单批次计算分位再拼接。必要证据不足单列缺口；不能把缺失当作已经低于推荐门槛。

指数按未舍入值降序。精确相同的指数明确并列，代码只决定稳定显示顺序；不同原始组合也可能产生相同指数。展示必须保留原始量、三个分位、P/V组分、共同N、分析日、20日窗口、有效性及与下一候选的比较，不能由展示层重新计算。完成技术复核后统一重算比较池，再裁剪最终展示数量；财务、行业、控盘与其他只给最终候选取得的补充证据不额外加分。

计算明细字段为 `raw_values`、`percentiles`（均以 `ret_20`、`directional_efficiency_20`、`up_amount_dominance_20` 为键）、`price_group`、`volume_group`、`recommendation_index`、`pool_size`、`status` 和 `missing_reasons`。旧研究保留其原始R/E/U与0–100指数口径；生产兼容recommendation_index的基点定义不可反套旧研究。技术摘要继续透传原始量与定义，不在展示层重算。

在固定比较池中，三个原始量均不差且至少一项更高的股票，指数严格更高。价格整体乘同一正常数、成交额整体换算单位不会改变原始比例或排序。高分只说明在本次比较池中较符合规则；整个范围下跌时高分仍可能对应负收益，不同日期或范围的分数不能直接比较绝对强弱。R与E共享价格输入，U也依赖价格涨跌方向，不能解释为三份独立确认。

验证区分两层：数学检查覆盖公式原值、共同池、支配一致性、尺度不变、并列、缺失与零分母；历史向前回放检查固定指数高分组次日入场后的五日成本后表现，并与旧20／5日非支配规则、20日单项、5日单项及同日有效池参照比较。历史成员重建、成交假设、重叠持有期、可用日期与失败窗口均需披露，不以数学检查通过替代收益有效性，不以回放自动修改权重或发布未来收益预测。

历史研究使用信号日可得数据选股，未来收益是否可计算不反过来改变候选和TopN。完整参照池有未知收益时保留严格完整池值未知，同时继续报告可计算子集均值及覆盖。相对比较只在双方收益均已知的同一日期上配对，不能直接相减不同日期集合的均值。可计算子集不能称为完整主板；未知收益不填零。

完整池缺失影响使用已知等权收益贡献K、未知权重w和纯多头参考收益−100%的下限，得到完整池均值下界 `L=K-w`。在TopN收益已知的同日集合上，`mean(TopN-L)` 是相对完整池平均超额的上界，仍负时可排除跑赢，非负时不能确认优势。令未知部分的加权平均收益为m，完整池为 `K+w*m`；使其与TopN均值相等的临界m只用于敏感性说明，不代表已取得或估计出的未知收益。w为零时不制造临界数。

分组诊断固定使用五组：按信号日未舍入指数的平均升序名次分位划分，第一组最低、第五组最高，精确同分归同组，允许空组。各组保留可计算子集、严格完整组、共同可计算日期统计及覆盖；最高组减最低组做同日配对。分组只检验收益梯度，不是再次评分、训练或参数寻优；空组和缺失不填中性收益。

研究 `analysis_type=recommendation_index_validation` 的顶层 `status=ok/partial/unavailable` 表示输出覆盖，收益判断分列于 `assessment`。已知样本平均收益非正时明确披露这一结果，与相对旧规则的改善、对单项基线的增量、缺失影响分别评价，不将负收益笼统归因于数据缺失。展示层保留原始收益小数、收益差、区间、日期、覆盖与逐事件记录，不重新计算统计或把收益差解释为推荐指数点。

`assessment.input_coverage` 仅评价输入与信号池，`future_reference_coverage` 单列后续参考收益覆盖；未来缺失不能反向修改输入状态。四个时间子期各自提供同日配对，不能直接相减日期集合不同的策略均值。逐日各组 `signal_codes` 完整保留于结构化结果，正文注明访问位置；原始统计、未知值和覆盖继续完整展示。

时间子期的同日配对保留在 `paired_comparisons`。局部比较结论 `exploratory_supported/not_supported/inconclusive` 与顶层输出覆盖状态分开，不能拿探索性收益结论替代覆盖判断。

### 历史研究的事件和成交约束

`tuijian_yanzheng.py` 的 `yanzheng_tuijian_zhishu` 只消费调用方传入的内存日线和权威日历，不自行取数或落盘。每隔5个交易日形成一组信号，在同日共同有效池比较旧指数TopN、旧20／5日非支配TopN、仅20日收益TopN、仅5日收益TopN及整池等权参照。旧二维规则以20日、5日收益均不差且至少一项更高定义支配，同层优先20日、再5日。

参考事件从次日开盘至第五个交易日收盘，默认往返比例成本0.142%。不生成年化或复利，不将独立事件组拼成重复投入同一本金的组合账本。TopN缺一项必要收益时整日期未知；完整池有未知收益时，仅严格完整池值未知，已知子集和覆盖仍保留。未来收益是否可计算不能反向改变输入信号池。

已观察到零成交或保守一字向上形态的阻买事件，以未投入现金零收益记账。阻卖事件有有效收盘价时，仅记录预留成本后的净值参考并跟踪延期退出，不能称为第五日已实现收益。一字形态4.5%方向变化规则只是研究假设，不是历史真实涨跌停核验。

当前存续目录、当前资格与末端历史质量筛选会带来样本偏差；前复权价格不是历史原始成交报价，日线有量不保证开盘成交，不能声称验证了历史完整主板。

MACD独立回放按实际确认日和次一市场交易日执行，保留停牌、封板、整手、真实成交额参与率、滑点与成本。`baseline_selected` 必须来自未使用待评估结构字段的历史时点流程，不使用未来失效状态改写信号日证据。研究保留大盘、行业、相对强弱、价量、范围、时间和参数稳定性；关键历史时点、成员、金额或跨度不足时，不宣布验证完成，也不反向训练或修改生产规则。
